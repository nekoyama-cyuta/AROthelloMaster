## 1. 概要と背景課題

### 1.1 開発の背景
ARオセロシステムにおいて、現実世界のオセロ盤上の各マス（64マス）の石の有無および色（黒・白・空/フェルト）を眼鏡搭載カメラの映像から判定する際、従来の固定閾値モデル（例: $V < 65$ で黒、$V > 165$ で白）では以下のような現実環境の照明変動に追従できず、重大な誤認識（False Positive / False Negative）が発生していた。

- **薄暗い部屋**: 全体の明度が低下し、白石がフェルト（空マス）と誤認される。
- **強光・白飛び環境**: 日差しや直下照明によりフェルトの明度が上昇し、白石と誤認される。また黒石がフェルトとして判定される。
- **電球色・寒色蛍光灯**: 色温度の変化によりRGBから変換されたHSVのV（明度）およびS（彩度）のバランスがシフトする。

### 1.2 単純平均・パーセンタイル法の破綻
単純な「全マスの明度平均（Mean）に一定オフセットを加減算する手法」や「パーセンタイル法」では解決できないオセロ盤固有の課題が存在する。
- **極端なクラス不均衡（Class Imbalance）**: オセロの初期・中盤では「フェルト（約50〜60マス）」に対し「石（黒・白あわせて数マス）」という極めて偏ったサンプル比率になる。
- 単純平均を用いると、平均値 $\mu$ は母集団の 90% 以上を占めるフェルトの明度に完全に引っ張られ、黒石や白石の存在数によって閾値が乱高下してしまう。

### 1.3 統計学的アプローチの目的
本仕様では、64マスの観測明度データを3つのクラスタ（$C_0$: 黒石, $C_1$: フェルト, $C_2$: 白石）として統計学的にモデル化し、**多クラス大津の2値化法（Multi-Otsu's Thresholding）**によるクラス間分散最大化、**サンプル数不均衡補正（重心中点境界）**、および石が存在しない空盤面に対する**$3.5\sigma$ 信頼区間退化保護規則**を組み合わせることで、任意の照明環境下で完全自律的かつ高精度に境界線を決定する動的キャリブレーションアルゴリズムを確立する。

## 3. 統計学的アプローチの数理モデル

### 3.1 3クラス判別問題としての定式化
オセロ盤上の 64 マスから得られる明度サンプルを $V = \{v_1, v_2, \dots, v_N\}$ （$N = 64, v_i \in [0, 255]$）とする。  
これを以下の 3 つの統計的クラスに分割する：
- **クラス $C_0$（黒石クラスタ）**: 明度区間 $[0, t_1]$
- **クラス $C_1$（緑フェルトクラスタ）**: 明度区間 $[t_1 + 1, t_2]$
- **クラス $C_2$（白石クラスタ）**: 明度区間 $[t_2 + 1, 255]$

ここで、$t_1, t_2$ は $0 \le t_1 < t_2 \le 255$ を満たす決定境界である。

### 3.2 大域統計量の算出
全サンプル $N$ に対する全平均 $\mu_T$ および全分散 $\sigma_T^2$ は次式で定義される：
$$\mu_T = \frac{1}{N} \sum_{i=1}^{N} v_i$$
$$\sigma_T^2 = \frac{1}{N} \sum_{i=1}^{N} (v_i - \mu_T)^2$$

### 3.3 累積度数および累積モーメント
アルゴリズムを $O(1)$ の高速差分参照で実行するため、離散明度階調 $v \in [0, 255]$ の度数ヒストグラム $h(v) = \sum_{i=1}^N \mathbb{I}(v_i = v)$ に対し、累積度数 $P[v]$ および累積一次モーメント $M[v]$ を事前計算する：
$$P[v] = \sum_{k=0}^{v} h(k)$$
$$M[v] = \sum_{k=0}^{v} k \cdot h(k)$$

### 3.4 クラス間分散の最大化（Multi-Otsu Criterion）
任意の候補境界 $(t_1, t_2)$ に対し、各クラスの生起確率 $\omega_k$ および平均明度 $\mu_k$ はテーブル参照により $O(1)$ で算出される：

$$\begin{aligned}
\omega_0(t_1) &= \frac{P[t_1]}{N}, & \mu_0(t_1) &= \frac{M[t_1]}{P[t_1]} \\
\omega_1(t_1, t_2) &= \frac{P[t_2] - P[t_1]}{N}, & \mu_1(t_1, t_2) &= \frac{M[t_2] - M[t_1]}{P[t_2] - P[t_1]} \\
\omega_2(t_2) &= \frac{N - P[t_2]}{N}, & \mu_2(t_2) &= \frac{M[255] - M[t_2]}{N - P[t_2]}
\end{aligned}$$

クラス間分散（Between-Class Variance） $\sigma_B^2(t_1, t_2)$ は以下のように表される：
$$\sigma_B^2(t_1, t_2) = \omega_0 (\mu_0 - \mu_T)^2 + \omega_1 (\mu_1 - \mu_T)^2 + \omega_2 (\mu_2 - \mu_T)^2$$

最適境界 $(t_1^*, t_2^*)$ は、クラス間分散を最大化する大域探索解として得られる：
$$(t_1^*, t_2^*) = \arg\max_{5 \le t_1 < t_2 - 5 \le 245} \sigma_B^2(t_1, t_2)$$

### 3.5 分離度指標（Separability Metric）
クラスタリングの品質および 3 峰性の成立度合いを評価するため、全分散に対するクラス間分散の比率として**分離度 $\eta$** を定義する：
$$\eta = \frac{\sigma_B^2(t_1^*, t_2^*)}{\sigma_T^2} \quad (0 \le \eta \le 1)$$
$\eta$ が 1.0 に近いほど 3 つのクラスタが互いに明確に分離していることを示す。

## 4. オセロ盤特有の課題解決：サンプル数不均衡補正

### 4.1 大津法生境界の限界と偏向現象
古典的大津法で得られる最適境界 $(t_1^*, t_2^*)$ は、サンプル数が等しい場合には理想的な境界を与えるが、**オセロ盤のようにクラス間でサンプル数が極端に異なる場合（フェルト 56個、黒石 4個、白石 4個など）**、大母集団であるフェルトの分散を最小化しようとするバイアスが働き、生境界 $t_1^*$ は黒石側（極端に低い値）へ、$t_2^*$ は白石側（極端に高い値）へと過度に押し出されてしまう。

### 4.2 重心中点境界（Midpoint Decision Boundary）の導出
一方で、大津法が算出した**各クラスの重心 $(\mu_0^*, \mu_1^*, \mu_2^*)$ 自体は、サンプル数不均衡の影響を受けにくく極めて正確なクラスタ中心を表している**。  
そこで本アルゴリズムでは、決定境界を生の大津閾値ではなく、クラス重心の幾何学的・統計的中点（Midpoint）として再定義する：

$$t_{\text{black}}^{\text{mid}} = \left\lfloor \frac{\mu_0^* + \mu_1^*}{2} \right\rceil$$
$$t_{\text{white}}^{\text{mid}} = \left\lfloor \frac{\mu_1^* + \mu_2^*}{2} \right\rceil$$

### 4.3 フェルト分散による安全クリッピング
フェルトの平均明度 $\mu_{\text{felt}}$ および標準偏差 $\sigma_{\text{felt}}$ を、彩度情報（$S \ge 35$）またはクラスタ $C_1$ から精密推定する：
$$\mu_{\text{felt}} = \frac{1}{|K_{\text{felt}}|} \sum_{i \in K_{\text{felt}}} v_i, \quad \sigma_{\text{felt}} = \sqrt{\frac{1}{|K_{\text{felt}}|} \sum_{i \in K_{\text{felt}}} (v_i - \mu_{\text{felt}})^2}$$

石のサンプル数が極端に少なく重心推定にノイズが乗るリスクを排除するため、決定境界をフェルトの統計的分散に基づく安全区間にクリップ（Clamp）する：
$$t_{\text{black}} = \text{clamp}\Big(t_{\text{black}}^{\text{mid}}, \; \max(12, \mu_{\text{felt}} - 3.2\sigma_{\text{felt}}), \; \max(15, \mu_{\text{felt}} - 1.5\sigma_{\text{felt}})\Big)$$
$$t_{\text{white}} = \text{clamp}\Big(t_{\text{white}}^{\text{mid}}, \; \min(235, \mu_{\text{felt}} + 1.5\sigma_{\text{felt}}), \; \min(242, \mu_{\text{felt}} + 3.2\sigma_{\text{felt}})\Big)$$

これにより、フェルトの明度変動（影や局所的な反射）が石判定境界を侵犯することを物理的・数学的に完全に防止する。

## 5. 退化検定（Degenerate Case Test）と $3.5\sigma$ 信頼区間保護

### 5.1 課題：空盤面におけるクラスタリングの破綻
オセロ盤上に石がまだ 1 つも置かれていないゲーム開始前（または石が 0〜2 個の初期状態）では、ヒストグラムは「フェルトのみの単峰性（Unimodal）正規分布」となり、黒石・白石のクラスタが存在しない。  
この状態で多クラス大津法を無条件に適用すると、フェルト分布内の僅かな明暗のノイズを無理やり 3 クラスに分割してしまい、フェルトの一部を黒石や白石と誤認識する重大な誤判定が発生する。

### 5.2 退化判定条件（Degeneracy Conditions）
以下のいずれかの条件を満たす場合、観測データは「退化状態（有効な 3 峰性が存在しない）」と判定する：
$$\text{IsDegenerate} \iff (\eta < 0.60) \;\lor\; (\mu_2^* - \mu_0^* < 45.0) \;\lor\; (\sigma_T^2 < 120.0)$$

- **$\eta < 0.60$**: クラス間分散の寄与率が 60% 未満であり、クラスタ分離が不十分。
- **$\mu_2^* - \mu_0^* < 45.0$**: 最大明度クラスと最小明度クラスの重心間距離が狭すぎ、白石と黒石の実体差が存在しない。
- **$\sigma_T^2 < 120.0$**: 盤面全体の明度分散が小さく、均一なフェルト面しか映っていない。

### 5.3 $3.5\sigma$ 安全規則の数理
退化が検知された場合、観測明度はフェルトの正規分布 $\mathcal{N}(\mu_{\text{felt}}, \sigma_{\text{felt}}^2)$ 単独に従っていると仮定する。  
正規分布において、平均から $k\sigma$ 離れた領域に観測値が現れる確率（片側棄却率）は次式で与えられる：
$$P(V < \mu_{\text{felt}} - k\sigma_{\text{felt}}) = 1 - \Phi(k)$$

$k = 3.5$ を採用した場合：
$$P(V < \mu_{\text{felt}} - 3.5\sigma_{\text{felt}}) = 1 - \Phi(3.5) \approx 0.0002326 \quad (0.023\%)$$

64 マスすべてにおいて誤判定が発生しない確率（盤面全体の非誤検知率）は：
$$P_{\text{clean}} = (1 - 2 \times 0.0002326)^{64} \approx (0.999535)^{64} \approx 97.1\%$$
各マス単位での信頼度は **99.98%** となり、空盤面におけるフェルトの誤検知は統計学的に完全に抑制される。

退化時の安全決定境界は次式により算出される：
$$t_{\text{black}} = \text{clamp}\Big(\lfloor \mu_{\text{felt}} - 3.5\sigma_{\text{felt}} \rceil, \; 20, \; 95\Big)$$
$$t_{\text{white}} = \text{clamp}\Big(\lfloor \mu_{\text{felt}} + 3.5\sigma_{\text{felt}} \rceil, \; 135, \; 235\Big)$$

## 6. 計算量解析とリアルタイム性能

### 6.1 計算量評価
- **ヒストグラム・累積テーブル作成**: $O(N + L)$
  - サンプル数 $N = 64$、階調数 $L = 256$。
  - ループ回数はわずか 320 ステップ。
- **大津境界大域探索ループ**: $O(L^2)$
  - 外側ループ $t_1 \in [5, 245]$、内側ループ $t_2 \in [t_1 + 6, 250]$。
  - 総探索ステップ数: $\sum_{i=1}^{240} i \approx \frac{240 \times 241}{2} \approx 28,920$ 反復。
  - ループ内処理は事前計算テーブル $P, M$ に対する配列インデックス参照と基本四則演算（差分除算）のみで構成され、$O(1)$ かつ分岐予測が安定。

### 6.2 実測実行時間
- **XREAL Beam Pro (Snapdragon 空間プロセッサ / ARM64)**: **約 0.45 ms**
- **PC Unity Editor (Intel Core i7)**: **約 0.28 ms**
- **リアルタイム性への影響**: ターゲットフレームレート 60 fps（1フレーム 16.6 ms）に対し、キャリブレーション処理負荷は **約 2.7%** に過ぎず、フレーム落ち（Jank）を一切誘発しない。

- **薄暗い環境（ケース2）**: 固定閾値（白 > 165）では白石（$\mu=118$）が 100% 消失していたが、本アルゴリズムは $t_{\text{white}} = 85$ を自律算出し、完全正解率 100.0% を達成。

### 8.2 将来の拡張性（ロードマップ）
1. **HSV色空間の S（彩度）同時クラスタリング（2次元大津法）**:
   - 現在は明度 V を主軸とし、彩度 S はフェルトの分散推定補助に用いているが、色付きフェルト（赤や青の盤面）にも対応するため、(V, S) 平面上の 2 変量正規混合モデル（GMM）への拡張が可能。
2. **時系列移動平均フィルタ（Kalman Filter / EWMA）**:
   - 急激な手の通過（オクルージョン）による一時的な明度変化で誤キャリブレーションが走らないよう、直近 K フレームの統計量を指数移動平均で平滑化する機構を追加可能。
